# S+ Plus Coffee — business card

| File | Use |
| --- | --- |
| `S-Plus-Coffee-business-card-PRINT.pdf` | Send this to the printer. Page 1 = front, page 2 = back. |
| `front.png`, `back.png` | High-res previews of each side (trimmed). |
| `preview.png` | Mockup of both sides. |

**Print specs:** US standard 3.5 × 2 in. The PDF is 3.75 × 2.25 in with a 0.125 in bleed on every side,
so choose "my file includes bleed" when ordering. All text sits inside the 0.125 in safe margin.
Fonts are embedded. Suggested stock: 16 pt or thicker, matte or soft-touch finish.

The QR code opens https://spluscoffee.com.

To edit: change `source/card.html` and re-export to PDF at 3.75 × 2.25 in with backgrounds on.
